# Resume Analyzer Full Stack

A full-stack resume analyzer with a FastAPI backend and a React + TypeScript frontend.

## Requirements

- Python 3.10 or newer
- Node.js 20.19+ or 22.12+
- An OpenAI API key for resume analysis

## Backend

In PowerShell, from the repository root:

```powershell
cd backend
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
# Add your OpenAI API key to backend/.env
uvicorn app.main:app --reload
```

The API runs at `http://localhost:8000`; interactive API documentation is at `http://localhost:8000/docs`.

## Frontend

In a second terminal, from the repository root:

```powershell
cd frontend
npm install
npm run dev
```

Open the URL printed by Vite. The development server proxies `/api` requests to the backend.

## Supported uploads

PDF and DOCX resumes are accepted. Analysis results are generated by the configured OpenAI model and are not persisted by this starter application.
